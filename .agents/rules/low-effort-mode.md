# Low-Effort Mode (Standing User Preference)

Use as little tokens as possible, low-medium effort only, don't think too much, just do what's requested as much as possible.

- Keep answers, plans, and code minimal; no extra explanation, preamble, or summary.
- Don't over-explore or over-engineer; take the simplest path that satisfies the request.
- Skip proactive extras the user didn't ask for.
